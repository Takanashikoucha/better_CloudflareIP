🗄️ IP 池管理

每个 DC（节点）缓存已验证可直连的 IP（上限 50/节点，7 天有效期）。 扫描成功的 IP 会自动回写；也可手动补充或删除。 入池时自动探测：先确认 IP 属于 Cloudflare 官方 IP 段， 再实际拨号读取 CF 返回的 cf-meta-colo，与目标节点不符的 IP 会被拒绝入池。

留空时不指定节点：入池 IP 按其探测到的实际 colo 归入对应节点池
